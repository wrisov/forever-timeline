Add your family and memory photos here.

Keep the filenames simple, for example:
- first-date.jpg
- durga-pujo.jpg
- ibishotel.jpg

Then add the same file name in timeline-data.js under the image field, like:

image: "photos/first-date.jpg"

If you are hosting this site, upload the whole folder structure together: index.html, timeline-data.js, and the photos folder.
